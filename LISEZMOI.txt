Fichiers modifiés (ajouts seulement) : public/index.html (lien « Bibliothèque » dans les 2 menus et le pied de page),
  public/admin.html (bouton « Bibliothèque » dans la barre du haut).
Étapes manuelles :
 1. Supabase > SQL Editor : relire puis exécuter supabase/bibliotheque.sql (nouvelles tables fonts et font_stats + bucket bibliotheque-fonts).
    Sans cela, le site fonctionne quand même : seuls le compteur de téléchargements et l'ajout de polices par l'admin attendent le SQL.
 2. Déposer le site sur GitHub (branche main) puis laisser Cloudflare redéployer. Le worker n'est pas modifié.
 3. Ouvrir /admin.html, se connecter, puis cliquer sur « Bibliothèque » pour gérer les polices ajoutées.
Sources : Google Fonts (dépôt google/fonts, 100 polices) et The League of Moveable Type (9 polices, licences vérifiées via Google Fonts).
Chaque fiche indique auteur et licence. Catégorie « Africaines » : vide, en attente de polices à redistribution vérifiée.
